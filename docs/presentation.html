Core Novelty

The Agri-Logic Engine

# scheduler.py — Context-Aware Decision Engine

def generate_schedule(disease, forecast, crop_stage):
    # Input: {Disease_Class, Rain%, Wind_Speed, Crop_Stage}

    if disease.type == "Fungal" and forecast.rain > 50%:
        return "⏳ DELAY Spraying — Rain expected"

    if crop_stage == "Flowering":
        return "🌸 Apply Potassium — Flowering stage"

    if forecast.wind > 20 km/h:
        return "💨 Avoid spray — High wind drift risk"

The engine combines Disease Classification, 5-Day Weather Forecast, and Crop Growth Stage to produce time-sensitive, actionable advice — not just labels.

Accessibility

Multilingual & Voice Support

🗣️

Text-to-Speech (TTS)

  • Voice-enabled advisory output
  • Optimized for low-latency feedback
  • Helps illiterate / semi-literate farmers
  • Plays advice aloud on mobile devices
🌐

Bilingual Interface

  • English — Full text + voice
  • Telugu (తెలుగు) — Full text + voice
  • advisories in farmer's native language
  • Bridges digital literacy gap

Unlike existing systems that only support text in Kannada/English, our system delivers voice output in Telugu — making AI truly accessible to rural farmers.
